# Vectorial Collective Website

Official web presence and landing page for the Vectorial Collective. 

## Overview

This repository houses the source code and static assets for the Vectorial Collective website (`vectorial-collective.github.io`). The site serves as the primary digital portal and landing page introducing our collective, our projects, and providing a submission interface[cite: 1].

## Structure

* **`index.html`** – Main landing page and entry point[cite: 1]
* **`dashboard.html`** – Collective member and status dashboard[cite: 1]
* **`projects.html`** – Showcase of active and past collective initiatives[cite: 1]
* **`submit.html`** – Interface for inquiries, applications, or project submissions[cite: 1]
* **`assets/`** – Central repository for branding media, including logos and imagery[cite: 1]
